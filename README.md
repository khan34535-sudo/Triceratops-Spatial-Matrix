# Triceratops-Spatial-Matrix
An interactive 6D spatial matrix for Triceratops holographic anatomical engine spanning globe, skull, body, teeth, and histology labs. Explore 3D–6D axes, spectral bands, chemistry focus, growth curves, palaeopathology, and population models. Prototype v0.5 by Asia Khan, behavioral UX researcher &amp; 3D spatial architect.
